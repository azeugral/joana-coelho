# Joana Coelho Tattoo · prévia

Site de apresentação de Joana Coelho (@joanacoelho.tattoo), fineline e microrrealismo. Feito por [L R G Z](https://lrgz.com.br).

Conceito: "a linha nunca levanta". Um único fio cai no eixo central, escreve a assinatura JC e tece tatuagens reais dela, onde a tinta verdadeira assenta, sobre a parede com luz de janela dos stories.

## Como montar

```
python tools/montar.py          # gera index.html a partir de tools/modelo.html
python tools/gerar_video.py     # posteres, capa do link e MP4 do celular
python tools/auditar.py         # 13 tamanhos + teste funcional
```
